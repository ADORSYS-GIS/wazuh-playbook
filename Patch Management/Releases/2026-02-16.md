# ✅ Deploy to Production Request

---

## 📌 Summary

Deploying updates to the Wazuh security platform, including:

- Upgrade of the Wazuh Manager to version **4.14.2**
- Performance improvements to custom **macOS FIM rules**
- Introduction of **cross-platform DLP detection** for macOS, Linux, and Windows

This deployment ensures users benefit from the latest security updates, improved performance, additional detection capabilities, and enhanced compliance coverage.

develop

4. Validate the health of the cluster
5. Perform functional tests on the cluster
